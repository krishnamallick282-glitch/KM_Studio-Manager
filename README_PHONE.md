# KM Studio Manager — Phone APK Build

1. Create a GitHub account.
2. Create a NEW repository, e.g. `KM-Studio-Manager`.
3. Upload ALL files/folders from this project to the repository (keep `.github/workflows/build-apk.yml`).
4. Open the repository → Actions.
5. Select `Build APK`.
6. Tap `Run workflow` (or push to main; it builds automatically).
7. When the workflow finishes, open the completed run.
8. Scroll to Artifacts and download `KM-Studio-Manager-debug`.
9. Extract the ZIP and install `app-debug.apk` on your Android phone.

If Android blocks installation, allow your browser/file manager to install unknown apps in Android settings, then install the APK.
